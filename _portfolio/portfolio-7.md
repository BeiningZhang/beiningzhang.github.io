High-level overview of production work (no proprietary details):

- Evolved exploratory buyer research into a project-owned service that combines niche, seller-mentioned, transaction-led, and other buyer-type-specific discovery strategies.
- Improved recall with country-aware public-web search, source-scoped retrieval, repeated evidence-backed extraction, and independently controlled search breadth and reasoning depth.
- Anchored seller and buyer context to canonical company identity while retaining per-method provenance through aggregation into one reviewable decision artifact.
- Migrated data authority through an expand–backfill–cutover–retire path, coordinating storage, permissions, typed service clients, API contracts, CI, and failure semantics.
- Persisted only complete discovery results and made failed runs explicit, preventing partial lists from appearing authoritative to advisers.

**Skills showcased:** Python, LLMs, web search, agentic retrieval, high-recall retrieval, source-scoped retrieval, REST APIs, typed service clients, data modelling, data authority migration, entity resolution, canonical identity, evidence provenance, provenance-preserving aggregation, CI/CD, failure semantics, human-in-the-loop review, workflow design.
