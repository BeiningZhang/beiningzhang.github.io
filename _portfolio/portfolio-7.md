High-level overview of production work (no proprietary details):

- Productionised exploratory buyer research as an asynchronous, deployable service with authoritative persistence and a documented internal integration contract.
- Combined niche, seller-mentioned, transaction-led, and other buyer-type-specific strategies while retaining source-specific provenance and comparable product-fit outputs.
- Built an accumulated buyer universe that preserves generated membership separately from adviser review state, so reruns do not erase scores, comments, starred candidates, or hidden decisions.
- Reconciled duplicate companies at the canonical data boundary while preserving project relationships and keeping ambiguous or conflicting matches explicit for review.
- Hardened operations with complete-response validation, bounded retries, candidate-level degradation, stable identifiers, and visible run failures so valid research survives partial processing.

**Skills showcased:** Python, LLMs, web search, agentic retrieval, high-recall retrieval, source-scoped retrieval, asynchronous services, REST APIs, typed service clients, API contract design, data modelling, authoritative persistence, entity resolution, identity reconciliation, canonical identity, ambiguity handling, evidence provenance, model-output validation, retry design, partial-failure recovery, operational observability, human-in-the-loop review, review-state modelling, workflow design.
